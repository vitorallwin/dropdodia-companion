# Drop do Dia — Curadoria Mercado Livre

Instalador oficial para Windows do companion local usado na curadoria e na geração de links afiliados do Mercado Livre.

## Download

[Baixar o instalador para Windows](https://github.com/vitorallwin/dropdodia-companion/releases/download/companion-v1.1.4/DropDoDia-Curadoria-Windows.zip)

Depois de baixar:

1. Extraia o ZIP.
2. Execute o `Instalar-Drop-do-Dia-1.1.4.exe` que está dentro.
3. Confirme a instalação do Windows.
4. Abra **Drop do Dia** pelo menu Iniciar ou pelo atalho criado.

Versão atual: **v1.1.4**

SHA-256 do pacote: `F04D2DCE9739BDD32FD1739583628D714A778F7D19F041F856CF3FFA3458B095`

O aplicativo mostra quando existe uma nova versão e permite instalar a atualização pelo próprio painel.

## Já uso a versão 1.0.7

A 1.0.7 **não se atualiza sozinha**: o atualizador daquela versão falha antes de conseguir executar qualquer pacote novo. A passagem para a 1.1.0 é manual, e só precisa ser feita uma vez.

[Baixar a migração da 1.0.7 para a 1.1.0](https://github.com/vitorallwin/dropdodia-companion/releases/download/companion-v1.1.0/DropDoDia-Migracao-1.0.7-para-1.1.0.zip)

Extraia e execute o `Migrar para 1.1.0.cmd`. Da 1.1.0 em diante, as atualizações voltam a ser automáticas pelo painel.

O código-fonte e as credenciais do Drop do Dia não são distribuídos neste repositório.
