# Drop do Dia — Curadoria Mercado Livre

Instalador oficial para Windows do companion local usado na curadoria e na geração de links afiliados do Mercado Livre.

## Download

[Baixar o instalador para Windows](https://github.com/vitorallwin/dropdodia-companion/raw/main/downloads/Instalar-Drop-do-Dia-1.0.7.exe)

Depois de baixar:

1. Execute o arquivo baixado.
2. Confirme a instalação do Windows.
3. Abra **Drop do Dia** pelo menu Iniciar ou pelo atalho criado.

Versão atual: **v1.0.7**

SHA-256 do instalador: `2EF4B4E794EFB8CFABABA59725EACDA49456CFB5C0306249D19A79DD34544F7A`

O aplicativo mostra quando existe uma nova versão e permite instalar a atualização pelo próprio painel. Instalações anteriores também recebem a versão atual pelo atualizador existente.

O código-fonte e as credenciais do Drop do Dia não são distribuídos neste repositório.
