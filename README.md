# Drop do Dia — Curadoria Mercado Livre

Instalador oficial para Windows do companion local usado na curadoria e na geração de links afiliados do Mercado Livre.

## Download

[Baixar o instalador para Windows](https://github.com/vitorallwin/dropdodia-companion/raw/main/downloads/DropDoDia-Curadoria-Windows-v1.0.1.zip)

Depois de baixar:

1. Extraia o arquivo ZIP.
2. Execute `Instalar Drop do Dia.cmd`.
3. Use o atalho **Drop do Dia - Curadoria** criado na Área de Trabalho.
